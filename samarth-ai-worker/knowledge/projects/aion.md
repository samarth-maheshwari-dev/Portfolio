# Project Aion

Project Aion is an Industrial Knowledge Intelligence Platform designed for the Economic Times (ET) AI Hackathon 2026. 

It transforms disconnected industrial documents, such as OEM manuals, Standard Operating Procedures (SOPs), P&IDs, and incident reports, into an AI-powered, continuously evolving knowledge system.

**Key Features:**
- Semantic Search using FAISS and sentence-transformers
- SQLite knowledge graph integration
- Cross-document reasoning and retrieval

This project showcases Samarth's ability to build complex, industry-specific AI solutions using modern embedding and retrieval techniques.
