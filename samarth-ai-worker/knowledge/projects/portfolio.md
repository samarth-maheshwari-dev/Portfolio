This portfolio website is designed and built by Samarth as an interactive technical showcase. 

It is built as an ultra-fast static HTML site using vanilla JavaScript, CSS custom properties, smooth scrolling mechanisms through Lenis, and premium animations powered by GSAP and WebGL (OGL). 

The portfolio also integrates a custom-built, RAG-powered digital representative (Samarth AI) that uses a Cloudflare Worker backend to retrieve contextual information and interact dynamically with the site layout.
