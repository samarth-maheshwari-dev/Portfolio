JARVIS is Samarth's personal AI assistant built with Python. It functions as an intelligent automation layer and voice-activated system control.

Instead of being a simple chatbot, JARVIS integrates directly with his computer. It demonstrates his ability to build practical, real-world AI applications that interact with the operating system, orchestrate multi-model AI logic, and provide a native Windows automation experience.

This project highlights his skills in Python, backend orchestration, automation, and applied AI engineering.
